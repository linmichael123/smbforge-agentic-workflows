# Data Flow & State Management

How data persists through the system — what's stored, where, and why.

## Storage Layers

```
┌──────────────────────────────────────────────────────────────┐
│                    Cloudflare Workers Runtime                  │
├─────────────────────┬──────────────────┬────────────────────┤
│     D1 Database     │   KV Namespace   │   In-Memory Cache  │
│  (Relational/SQL)   │  (Key-Value)     │   (per-request)    │
├─────────────────────┼──────────────────┼────────────────────┤
│ Conversations       │ Client skills    │ Tool call results   │
│ Leads               │ Config flags     │ LLM response cache │
│ Invoice records     │ Session state    │                    │
│ Review responses    │ Phone-number     │                    │
│ Conversation flags  │   mapping        │                    │
│ Form attempts       │ Opt-out list     │                    │
│ Campaign consents   │ Escalation data  │                    │
└─────────────────────┴──────────────────┴────────────────────┘
```

## D1 Database Schema (Core Tables)

### conversations
The primary record of every customer interaction.

| Column | Type | Purpose |
|--------|------|---------|
| `id` | INTEGER PK | Auto-increment |
| `tenant_id` | TEXT | Client identifier (e.g., "smb-forge", "client-plumber-co") |
| `customer_phone` | TEXT | Sender's phone number |
| `messages` | JSON | Full message history — serialized array of `{role, content, timestamp}` |
| `status` | TEXT | `active` / `resolved` / `escalated` |
| `escalation_reason` | TEXT | Why it was escalated (if applicable) |
| `journey` | TEXT | Current active journey: `booking` / `ordering` / `emergency` / `info` |
| `created_at` | TEXT | ISO 8601 timestamp |
| `updated_at` | TEXT | ISO 8601 timestamp |

### leads
Outbound lead tracking across email, SMS, and form channels.

| Column | Type | Purpose |
|--------|------|---------|
| `id` | TEXT UUID | Unique lead identifier |
| `name` | TEXT | Business name |
| `phone` | TEXT | Contact phone |
| `website` | TEXT | Business website |
| `ownerEmail` | TEXT | Discovered owner email |
| `segment` | TEXT | Target segment assignment |
| `status` | TEXT | `scraped` / `ready` / `contacted` / `not_icp` / etc. |
| `priority` | INTEGER | Lead score (1-10) |
| `scrapedAt` | INTEGER | Epoch millis of scrape |

### conversation_flags
Quality monitoring flags generated by the hourly cron.

| Column | Type | Purpose |
|--------|------|---------|
| `id` | INTEGER PK | Auto-increment |
| `conversation_id` | INTEGER FK | Points to conversations |
| `flag_type` | TEXT | `stuck` / `bot_unresponsive` / `escalation_unresolved` / etc. |
| `severity` | TEXT | `critical` / `warning` / `info` |
| `notified` | BOOLEAN | Whether owner was alerted |
| `reviewed` | BOOLEAN | Whether human has reviewed |
| `review_notes` | TEXT | Notes from review |

## State Machine: Conversation Lifecycle

```
                    ┌─────────────────────────────────────────────┐
                    │               NEW MESSAGE                    │
                    │  Customer texts or calls the business line   │
                    └─────────────────────┬───────────────────────┘
                                          │
                                          ▼
                    ┌─────────────────────────────────────────────┐
                    │           CLIENT RESOLUTION                  │
                    │  Look up phone-number-to-client mapping      │
                    │  Load client skill file from KV              │
                    └─────────────────────┬───────────────────────┘
                                          │
                                          ▼
                    ┌─────────────────────────────────────────────┐
                    │         CONVERSATION ORCHESTRATION           │
                    │  Build system prompt with client context     │
                    │  Append conversation history (last N msgs)   │
                    │  Call LLM with available tools               │
                    └──────┬──────────────────────┬───────────────┘
                           │                      │
                           ▼                      ▼
              ┌──────────────────────┐  ┌──────────────────────┐
              │   TOOL CALL MADE     │  │  TEXT RESPONSE       │
              │  Execute tool →      │  │  Generate + send     │
              │  Re-enter LLM loop   │  │  Log to D1           │
              │  Max 3 tool rounds   │  │  Check limits        │
              └──────────────────────┘  └──────────────────────┘
                           │                      │
                           └──────────┬───────────┘
                                      ▼
                    ┌─────────────────────────────────────────────┐
                    │          POST-PROCESSING                     │
                    │  Save to D1 conversations table              │
                    │  Check if escalation needed                  │
                    │  Check conversation limits (8/12 turns)      │
                    │  If idle 24h → auto-resolve                  │
                    └─────────────────────────────────────────────┘
```

## Data Retention

| Data Type | Retention | Rationale |
|-----------|-----------|-----------|
| Conversation messages | 30 days active, then summarized | PII minimization |
| Lead records | Indefinite | Outbound pipeline state |
| Flags (reviewed) | 90 days | Audit trail |
| Client skills | Indefinite | Business configuration |
| Opt-out records | Indefinite | Regulatory compliance |
| Form attempts | 30 days | Funnel analysis |
| Invoices | 7 years (business records) | Accounting requirement |
